## About the Game

**Final Notice** is a visual novel prototype created by **Orpita Community** for the **Spooktober 8th Annual Visual Novel Jam** (September 2026), where entries are built around spooky and Halloween themes. Playable in the browser.

> "It's such a quiet, heartfelt game... There's some really beautiful art here, and gorgeous colour work in the backgrounds and items."
>
> — breadinc, from the game's jam page comments

> **Note:** this repository is named `Spooktober` after the jam; the game itself is **Final Notice**.
